# 🔒 SecureManuf Pro - End-to-End Encryption Manufacturing System

## 📋 Project Overview

SecureManuf Pro is a complete **End-to-End Encryption (E2EE)** demonstration system for manufacturing environments. It shows how sensitive manufacturing data can be encrypted before storage and only decrypted by authorized personnel.

### 🎯 Key Features

- ✅ **Role-Based Access Control** (Admin, Operator, QC, Maintenance)
- ✅ **Real E2EE** - Messages encrypted before database storage
- ✅ **SQLite Database** - All data stored securely
- ✅ **Login Tracking** - Monitor after-hours access
- ✅ **Audit Logging** - Complete system audit trail
- ✅ **Professional UI** - Modern, responsive design
- ✅ **Priority System** - Critical/High/Normal/Low messages
- ✅ **Unread Tracking** - Know which messages are pending
